# يا مساعد (YaMosaed) 🇪🇬

مساعد شخصي عربي مصري ذكي لأندرويد، يجمع بين قوة الذكاء الاصطناعي عبر **Gemini API** لفهم الأوامر والحديث الطبيعي، وقدرات الوكيل المحلي للعمل دون إنترنت، مع شخصية بصرية تفاعلية (عيون متحركة).

---

## ✨ المميزات الرئيسية

1. **الذكاء والمحادثة (Gemini API):**
   - فهم الأوامر الصوتية والكتابية بالعامية المصرية.
   - استيعاب سياق المحادثة والضمائر («شغّلها»، «اللي بعدها»، «كرر ده»).
   - دعم كامل للعمل دون إنترنت عبر محرك قواعد محلي مصري.

2. **الشخصية البصرية (Animated Eyes):**
   - عيون متحركة ناعمة بـ 7 حالات مختلفة: انتظار (IDLE)، استماع (LISTENING)، تفكير (THINKING)، تحدث (SPEAKING)، تنفيذ (EXECUTING)، نجاح (SUCCESS)، وخطأ (ERROR).

3. **التحكم في الموسيقى (Spotify & SoundCloud):**
   - فتح البحث بروابط عميقة واختيار النتيجة تلقائيًا عبر `AccessibilityService`.
   - التحكم الكامل في مشغلات الوسائط (تشغيل / إيقاف مؤقت / التالي / السابق) عبر `NotificationListenerService`.
   - قراءة اسم الأغنية الحالية والفنان عند توفرها.

4. **المهام والتذكيرات المجدولة:**
   - شاشة مخصصة لإدارة مهام اليوم مع إمكانية الإضافة والإكمال والحذف.
   - تنبيهات منبهات دقيقة عبر `AlarmManager` و `TaskReminderReceiver`.

5. **أدوات المساعد اليومية:**
   - الطقس الحقيقي باللغة العربية عبر Open-Meteo.
   - الوقت والتاريخ بالتنسيق المصري.
   - المنبهات عبر تطبيق الساعة والتايمر الدقيق.
   - البحث عن الأماكن القريبة عبر خرائط Google.

---

## 🔒 إعداد الصلاحيات

1. **الميكروفون (Microphone):** يُطلب مباشرة عند الضغط على زر التحدث.
2. **الوصول للإشعارات (Notification Access):** لتفعيل أزرار التحكم في الموسيقى وقراءة بيانات الأغنية الحالية.
3. **إمكانية الوصول (Accessibility Service):** لاختيار أول نتيجة مطابقة تلقائيًا في Spotify.
4. **المنبهات الدقيقة (Exact Alarms):** لضمان انطلاق التايمر وتذكيرات المهام في موعدها الدقيق.

## 🚀 البناء والتحميل عبر GitHub Actions

الملف `.github/workflows/android-apk.yml` يقوم تلقائيًا بـ:
- فك تشفير مفتاح التوقيع `debug.keystore`.
- تجهيز متغيرات البيئة من `.env.example`.
- تشغيل اختبارات الوحدات (`testDebugUnitTest`).
- بناء حزمة `app-debug.apk` ورفعها كـ Artifact جاهز للتنزيل المباشر.
